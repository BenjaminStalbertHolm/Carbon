# CARBON

First-person psychological horror, built in Godot 4.3-stable (GDScript,
Compatibility renderer). The full specification is `CARBON_SPEC.md`. Open
decisions are in `QUESTIONS.md`.

## Status

- M0 (project setup, folder structure, autoload stubs, fonts, asset generators): done. See "Verified (M0)" below.
- M1 (rendering pipeline: 320x240 SubViewport, PS1 spatial and post shaders, fog, resolution switching): done. See "Verified (M1)" below.
- M2 (Hall C geometry): in progress.
- M3 to M11: logic for the day flow, the typewriter, redaction, corrections, endings and the text is done and tested headless. Presentation (player, typewriter view, read view, audio, front end, endings sequences, debug console) is being built.

## Requirements

- Godot 4.3-stable, plus its export templates for any platform you export.
- Python 3.12 or newer for the asset tools (versions pinned in `tools/requirements.txt`).

## Generate the assets

Run from the repo root. The scripts work from any working directory.

```
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r tools/requirements.txt
python3 tools/gen_textures.py      # assets/textures/*.png (spec 5.7)
python3 tools/gen_audio.py         # assets/audio/*.wav (spec 11.2, 11.3)
```

The generated files are committed. Rerunning the scripts on Linux reproduces
them byte for byte. This has not yet been checked on macOS.

## Run the M0 checks

```
godot --headless --path . --script res://tests/run_tests.gd
```

Exit code 0 means every check passed.

## Rendering test scene (M1)

`tests/psx_test.tscn` is a dev-only scene: a textured cube, a floor with a high-contrast checker, and fog. It is excluded from exports.

```
godot --path . tests/psx_test.tscn                 # keys: 1 = 320x240, 2 = 640x480, 3 = focus view, D = dither
godot --path . tests/psx_test.tscn -- --selftest   # toggle checks, exit 0 on success
```

Arguments after `--`: `--res=high`, `--focus`, `--dither=off`, `--wobble=0`, `--frames=<n>`, `--shot=<png>`. Headless runs have no GL, so use `xvfb-run` on Linux when you need rendered output.

## Export

`export_presets.cfg` defines three presets:

| Preset | Output |
|---|---|
| Windows Desktop | `build/windows/CARBON.exe` |
| Linux | `build/linux/CARBON.x86_64` |
| macOS | `build/macos/CARBON.zip` |

The macOS preset builds a universal app (Apple Silicon and Intel), ad-hoc
signed. Gatekeeper blocks a downloaded build the first time it is opened, so
open it with right-click, then Open. The bundle identifier is a placeholder
and signing is undecided; see `QUESTIONS.md` QUESTION-1 and QUESTION-2.

Spec section 1 lists Windows and Linux only. macOS was added at the owner's
request. `CARBON_SPEC.md` is kept unchanged, as spec section 3.2 requires.

## Conventions

- Asset file names are lowercase. Code must reference them with the exact
  same case. macOS's default file system ignores case and Linux's does not,
  so a mismatch will work on one and fail on the other.
- Only `user://` is written to at runtime (spec section 0, rule 7).

## Choices the spec leaves open

These are internal or invisible unless noted. Decisions a player would notice
are in `QUESTIONS.md`.

- Texture value noise is one offset per pixel, applied equally to R, G and B.
- The frosted glass texture is RGBA with alpha 178 (0.7 × 255, rounded).
- Each generated file draws from its own RNG seeded from (412, file name), so
  output does not depend on generation order.
- Ambient beds (spec 11.2) are generated by `tools/gen_audio.py`, because spec
  section 0 rule 5 says all sounds come from the two scripts.
- Frequency sweeps (tube, whoosh, door) move in log-frequency.
- Seamless loops (`marker_stroke`, the three beds) are built with FFT-domain
  filters or exact phase closure, so they loop without a seam.
- Dither offset is a Bayer rank scaled to a maximum of ±1/32 before 5-bit quantisation.
- Fog is applied after lighting: the lit colour is scaled by (1 − fog) and the fog colour is added as emission.
- Affine texture mapping uses UV×w and w varyings, divided per pixel (spec 4.2). The GPU's perspective-correct interpolation cancels out, which leaves the screen-linear mapping the PS1 used.
- The snap grid is the project-level shader global `psx_snap_grid`, declared in `project.godot`. Without that declaration, the export-time shader check fails.

## Tests

Run from the repo root. Each exits 0 when every check passes.

```
godot --headless --path . --script res://tests/run_tests.gd                    # M0 project and asset checks
godot --headless --path . --script res://tests/unit/test_logic.gd              # text, documents, redaction, corrections, memos, clock
godot --headless --path . --script res://tests/unit/test_typewriter.gd         # typewriter rules and ghost queue
godot --headless --path . --script res://tests/unit/test_playthrough_day1.gd   # Day 1 and the Day 2 morning, through the real content
godot --headless --path . --script res://tests/unit/test_playthrough_compliant.gd  # acceptance test 1: a compliant five-day run
godot --headless --path . --script res://tests/unit/test_acceptance_logic.gd   # acceptance tests 4, 5, 6 and 10 (logic level)
python3 tools/check_text.py                                                    # acceptance test 13: text fidelity
```

Visual checks run under a virtual display: `xvfb-run -a -s "-screen 0 1280x1024x24" godot ...`.

Acceptance status, by spec section 20, is kept in tests/acceptance/ACCEPTANCE.md once it exists.

## Verified (M0)

Checked on Linux with Godot 4.3-stable (with its export templates) and Python 3.13 (numpy 2.5.3, scipy 1.18.1, Pillow 12.3.0).

- `tests/run_tests.gd`: 89 checks pass, 0 fail.
- Asset generators: 12 textures and 34 WAV files are written. Every WAV is 44.1 kHz, 16-bit, mono, and matches its spec length and peak (or RMS for the beds). Both loops close: `marker_stroke` and the three beds. A rerun reproduces every committed asset byte for byte.
- Exports, run headless from Linux:
  - Windows Desktop: a PE32+ x86-64 executable.
  - Linux: an ELF x86-64 executable. It starts and exits cleanly.
  - macOS: `CARBON.app` inside the zip. The binary is universal (x86_64 and arm64), ad-hoc signed, with bundle identifier `com.example.carbon`, category Games and high-resolution support on.

Not verified: nothing has been run on a Mac, so macOS launch, Gatekeeper behaviour, and rendering there are untested. The Windows executable has not been run. The Linux build has only been checked to start and exit; rendering is checked in M1.

The macOS export needs ETC2/ASTC texture import (`rendering/textures/vram_compression/import_etc2_astc`); Godot refuses arm64 and universal exports without it.

## Verified (M1)

Checked on Linux under Xvfb (OpenGL 4.5 core, Mesa llvmpipe), Godot 4.3-stable.

- Self-test (`tests/psx_test.tscn -- --selftest`): 10 toggle and state checks pass. The checks cover the 320x240 default, the HIGH setting, focus view on and off, the snap grid at each resolution, and the dither switch. There are no shader errors.
- Screenshots (1280x960) show the expected effects:
  - Vertex snapping: the cube's edges jitter as it turns.
  - Affine warp: the checker floor's lines bend and shear.
  - Dither: the output changes on about 695,000 of 1.2 million pixels when dither is turned off.
  - Fog: the far floor fades toward #2A2A26.
- Every output value sits on the 32-level 5-bit grid, with zero off-grid pixels in every frame checked.
- Integer scale: 4× at 320x240 and 2× at 640x480, both filling 1280x960. At a 1000x800 window the picture is 960x720, centred with 20 px side bars. At 300x200 it is 266x200 with 4:3 kept, centred.
- Export: the Linux build is clean, with no shader errors. The test scene is absent from the pck.

Not verified: rendering on a real GPU and on macOS. Everything above was rendered in software.
